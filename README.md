# Meetup Project

Responsive web application inspired by the Meetup platform.

## Features

- Responsive design (Desktop and Mobile)
- Event filtering by:
  - Type
  - Distance
  - Category
  - Date
- Google Maps integration
- Semantic HTML5
- CSS Flexbox & Grid
- Vanilla JavaScript

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Pages

- Home page
- Events page
