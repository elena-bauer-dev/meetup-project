# Meetup Project

Responsive web application inspired by the Meetup platform.

## Features

- Responsive design (Desktop and Mobile)
- Event filtering by:
  - Type
  - Distance
  - Category
  - Date
- Google Maps integration
- Dynamic event rendering with JavaScript
- Semantic HTML5
- CSS Flexbox & Grid
- Vanilla JavaScript

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Pages

- Home page
- Events page

## Getting Started

No installation or dependencies are required.

Simply open index.html in your browser or use a local development server such as VS Code Live Server.
